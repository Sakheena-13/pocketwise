# PocketWise – Personal Finance Simulator

## About the Project

PocketWise is a personal finance management website that helps users track expenses, manage financial goals, monitor bills, and simulate financial decisions before spending money.

## Features

* **Dashboard:** View an overview of your financial information.
* **Transactions:** Track income and expenses.
* **Money Lab:** Simulate purchases and understand their financial impact before making a decision.
* **Financial Goals:** Create and track savings goals.
* **Commitments:** Manage recurring bills and financial obligations.
* **Financial Health:** Review your overall financial position.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage (if implemented in the application)

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Explore the available sections and test the features.

## Purpose

The goal of PocketWise is to encourage better financial decisions by helping users understand the potential impact of spending and saving choices.
